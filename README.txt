Campus Lost & Found - Web App
RUN:   python server.py      (Python 3.8+, koi package install nahi karna)
OPEN:  http://localhost:8000  (same WiFi par dusre phone/PC se: http://<is-PC-ka-IP>:8000)
Pehli baar: "Set up the owner account" screen aati hai - woh account Owner banta hai.
Demo items nahi chahiye to:  set CLF_NO_DEMO=1  (Windows)  phir server chalayein.
Data: data/clf.db (SQLite) aur data/uploads/ (photos). Backup ke liye yeh folder copy karein.
